# dump

> a memory dump, hopefully readable.

A personal place for things I build, learn, use, and occasionally break.
Mostly computers. Sometimes other stuff.

## Writing

Posts are `.mdx` files in [`content/posts/`](content/posts/). Add one, write it,
commit, push — Vercel deploys it. No code changes needed.
[`content/README.md`](content/README.md) has the details.

## Development

`nvm use` (Node 24), then `npm install`. Scripts: `dev`, `build`, `start`,
`lint`, `typecheck`, `test`, `format`. See `package.json`.

Stack: Next.js (App Router), TypeScript, MDX, Shiki, Jest. Deployed on Vercel.
