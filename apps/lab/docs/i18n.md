# Lab localization

Lab-specific rules for English and Brazilian Portuguese. The contract that
applies to every app is [docs/i18n.md](../../../docs/i18n.md); this file records
how Lab implements it and the decisions that are particular to experiments.

## State

All three experiments (`001`, `002`, `003`) exist in English and Brazilian
Portuguese with their own slugs, and so do the home, search, Terms and Privacy
pages. Lab's Portuguese footer links its own `/pt/terms/` and `/pt/privacy/`
(faithful translations; the English text stays authoritative) without the
"em inglês" qualifier. Lab's 404 stays English, as for Docs (see
[404 behavior](../../../docs/i18n.md#404-behavior)).

## Identifiers are not translated

Program values that a bench shows or uses (Orbit's status values and field
names, Sweep's category directory names, registers, opcodes, hex) stay exact in
Portuguese and carry `lang="en"`. A translated descriptive label may sit beside
one, clearly secondary, but never replaces it. The classifier's destination
preview and its category column therefore always agree.

## Counts

Counted phrases live in the catalogs as complete sentences with a `{count}`
placeholder (`PluralForms` in `src/lib/plural.ts`: `one`, `other`, optional
`none`). The category comes from `Intl.PluralRules` for the registry's
`intlLocale`; nothing hand-codes a language's rule.

- English: `1 file classified`, `0 files classified`, `2 files classified`.
  Zero is plural, as CLDR says.
- Brazilian Portuguese: CLDR files both 0 and 1 under "one" (`0,5 arquivo`,
  `1 arquivo`), which is correct grammar but reads wrong for a bare zero in an
  interface, with the singular (`0 arquivo classificado`) or the plural
  (`0 arquivos classificados`). Every Portuguese counted phrase therefore
  supplies `none`: `nenhum arquivo classificado`, `nenhum experimento`. It says
  what the number says and adds nothing. Two and more use the plural
  (`2 arquivos classificados`, `11`, `21`, `100`).
- Counts are whole numbers; a fraction or a negative number throws. CLDR's
  "many" for round millions in Portuguese is not used (no count in Lab can
  reach it) and falls to the plural.
- A test requires a `none` sentence for every counted phrase of every locale
  whose CLDR rule files zero under "one", so a new phrase or locale cannot
  ship the bare form.
- Only two phrases depend on a number: the index filter result
  (`N experiments`) and the classifier summary (`N files classified`). Section
  progress (`2 / 5`) is a position, not a count.

## Agreement with a title

A notebook entry reads "title published". A Portuguese participle must agree
with the title's number, so a plural title (`estados de execução`) sets
`titlePlural` on its record and the catalog picks `registrados` instead of
`registrado`.

## Notes

An experiment's `notes` paragraph (provenance: pinned revision, limits) renders
under Fidelity in both languages. Before this localization the Portuguese
pages rendered it and the English pages did not. The English pages did render
it before the shared-design migration (`3e91107`), which dropped it while
restyling the layout, and the Portuguese layout added a Portuguese-only branch
later (`2894b3d`). The English records always held the text, so showing it in
both languages restores the original behavior instead of inventing content.

## Existing Portuguese text

The published Portuguese experiment `001` predates the rest of the
localization. Its public text is preserved wherever it was accurate: title,
description, question, notes, the "O que funciona aqui" heading, the notebook
suffix ("registrado"), the Fidelity rows and the search page title are
unchanged, and a test pins them. What changed, deliberately:

- the home page's notebook intro now translates the English sentence ("Registros
  curtos e datados: o que mudou, o que quebrou, o que foi respondido.") instead
  of being a different sentence;
- the classifier shows Sweep's real category values (`Images`, `Documents`, ...)
  with the translation beside them, so the table agrees with the destination
  path, and the "why" heading and explanation use the real value;
- the Related section lists the same destinations as the English page (the
  Sweep docs and the two Dump posts, the latter marked "em inglês"); the
  separate GitHub row went because the same link is in the page header in both
  languages;
- the search page suggestions, the footer's Terms and Privacy links (no longer
  "em inglês") and the previous/next pager follow the new pages.

## Dates

Dates, including the experiment `created` date, render with the page locale's
`Intl` formatting (`September 13, 2026`, `13 de setembro de 2026`) in
`<time datetime>` with the ISO value.
