# Deployment

## Intended model

docs.raioviajante.com deploys to Vercel as its own separate deployment/project, distinct from raioviajante.com and the rest of the ecosystem. Each subdomain in the RaioViajante ecosystem is its own repository and its own deployment.

## DNS

The DNS zone for `raioviajante.com` is managed externally, outside this repository. The `docs` subdomain will later be pointed at the Vercel deployment once it exists. No DNS records are documented here yet, since none have been created.

No deployment exists yet. This document will be updated with the actual Vercel project configuration and any relevant deployment notes once the site is initialized and deployed for the first time.
