# Development

## Status

The Astro/Starlight application has been initialized. The application foundation exists (config, TypeScript setup, a single public index page); the RaioViajante visual identity and the planned project documentation have not been implemented yet.

## Stack

- **Package manager:** pnpm
- **Framework:** Astro
- **Documentation framework:** Starlight
- **Language:** TypeScript
- **Content format:** Markdown / MDX
- **Search:** Pagefind, generated by Starlight at build time
- **Dependencies:** kept minimal — only `astro` and `@astrojs/starlight` in production, `typescript` and `@astrojs/check` in development

## Commands

- `pnpm install` — install dependencies
- `pnpm dev` — start the local development server
- `pnpm build` — produce a production build in `dist/` (also builds the Pagefind search index)
- `pnpm preview` — serve the production build locally
- `pnpm check` — run Astro/TypeScript diagnostics (`astro check`)

## Conventions

- **Commits:** meaningful, Conventional Commits, one coherent change per commit (see `AGENTS.md`)
- **Validation:** run `pnpm check` and `pnpm build` before committing changes to the application
