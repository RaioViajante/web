# Development

## Status

The Astro/Starlight application has not been initialized yet. This document lists the intended conventions only; it will be updated with real commands and workflows once the application exists.

## Intended conventions

- **Package manager:** pnpm
- **Framework:** Astro
- **Documentation framework:** Starlight
- **Language:** TypeScript
- **Content format:** Markdown / MDX
- **Dependencies:** kept minimal — only what the stack above actually requires
- **Commits:** meaningful, Conventional Commits, one coherent change per commit (see `AGENTS.md`)
- **Validation:** work is validated (build/lint/typecheck once available; careful review until then) before committing

## Not yet defined

Actual commands (`pnpm install`, `pnpm dev`, `pnpm build`, lint/typecheck scripts, etc.) do not exist yet and are not documented here to avoid implying a working setup that isn't there. This file will be filled in once Astro and Starlight are initialized.
